# RehabScreen Lab 高保真 UI V3

## 唯一母版

以 `screens/04-standard-screening-hub.png` 为视觉母版。后续页面只替换内容，不改变设计语言。

## 锁定规则

- 画布：竖屏移动端，统一比例与安全区。
- 背景：暖象牙白。
- 主色：深森林绿；辅助色：低饱和鼠尾草绿；提醒色：克制琥珀色。
- 页头：标题居中；二级页面左侧返回；同一字号、字重和垂直位置。
- 内容：统一左右边距、圆角卡片、轻柔阴影和纵向间距。
- 图标：统一细线图标，不混用照片、3D 图标或其他图标家族。
- 状态：绿色表示完成或可用；琥珀色表示待完成、缺失或需关注；灰绿色表示可选。
- 主按钮：统一高度、圆角、深绿色和白色文字。
- 底部导航：固定为“任务 / 学生 / 采集 / 报告 / 我的”，每页只允许一个选中项。
- 文案边界：筛查不是诊断；手机不自动计算 ATR；深蹲不是正式报告必选项。

## 页面与导航状态

1. `01-screening-tasks.png`：早筛任务；选中“任务”。
2. `02-gait-silhouette-capture.png`：步态剪影采集；选中“采集”。
3. `03-initial-triage-result.png`：初筛结果；选中“报告”。
4. `04-standard-screening-hub.png`：标准筛查；选中“采集”。
5. `05-adams-manual-record.png`：Adams 前屈记录；选中“采集”。
6. `06-formal-report-readiness.png`：正式报告条件；选中“报告”。
