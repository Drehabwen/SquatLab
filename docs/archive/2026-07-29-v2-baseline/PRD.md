# PRD: RehabScreenLab 青少年姿态与脊柱早筛系统 V2.0

## 1. 产品摘要

RehabScreenLab 是面向学校、基层机构和康复筛查场景的青少年姿态与脊柱风险筛查闭环系统。产品以低门槛的步态剪影作为一级分诊入口，对需要进一步确认的对象再安排静态体态、Adams 前屈和人工复核；深蹲保留为可选的动作控制证据。

产品解决的不是“用 AI 诊断脊柱侧弯”，而是：

- 快速识别需要进一步筛查的人；
- 让采集质量不足、结果不确定和多协议冲突都有明确去向；
- 将初筛、标准筛查、报告、复采、复核和复测连接成可追踪闭环；
- 降低学校批量筛查对脱衣、专业设备和操作者经验的依赖。

## 2. 产品定位

产品定位为：

- 青少年姿态与脊柱风险筛查工具；
- 批量初筛与复核任务管理工具；
- 多协议证据整合与复测跟踪工具；
- 本地优先、隐私友好的移动采集端。

产品不定位为：

- 医疗诊断软件；
- Cobb 角估算工具；
- X 光或专科评估的替代品；
- 自动生成治疗处方的系统；
- 用单个分数替代专业判断的平台。

## 3. 设计依据与证据边界

剪影论文与严格复核实验为产品提供以下设计方向：

- 全身轮廓的方向性位置包含可用于分诊的信号；
- 轻量几何模型可接近复杂模型，适合移动端本地推理；
- 将左右边缘压缩成无方向“不对称分数”会丢失信息；
- 最低身体分段是候选信号，但不足以支持“只看脚踝”的产品；
- 低置信度、边界和冲突病例必须升级到标准筛查或人工复核。

这些结果来自二维步态剪影研究，尚不能证明：

- 单张静态照片可达到同等性能；
- 任一固定的 8 个特征可作为稳定医学规则；
- 最低剪影分段等同于解剖学踝关节生物标志物；
- 模型概率可直接解释为患病概率；
- 模型可用于诊断或 Cobb 角估计。

## 4. 目标用户

### 4.1 现场筛查人员

- 学校卫生人员；
- 康复治疗师或运动康复人员；
- 经培训的基层筛查操作员。

核心需求：快速建档、连续采集、自动质控、明确下一步动作。

### 4.2 专业复核人员

- 康复治疗师；
- 脊柱侧弯筛查相关专业人员；
- 负责报告审核与转介的人员。

核心需求：查看原始证据、理解协议一致性、处理边界和冲突结果。

### 4.3 组织管理人员

核心需求：查看任务进度、复采阻塞、待复核数量、报告完成率和复测到期情况。

## 5. 核心问题

- 对所有学生执行完整 Adams 和动作测试，现场成本过高。
- 传统目测依赖经验，容易出现操作者差异。
- 采集质量常被主观判断，劣质输入仍可能生成结论。
- 单协议异常缺少交叉验证，难以区分稳定风险与偶然波动。
- 边界结果、冲突结果和复测任务没有闭环状态。
- 原有文档以单一深蹲产品为中心，与当前联合筛查代码不一致。

## 6. 产品目标

### 6.1 V2.0 目标

- 建立“一级剪影分诊 → 二级标准筛查 → 报告/复核/复测”的完整流程。
- 支持自动采集质量门槛，不合格数据不得强行生成风险结论。
- 支持多协议结构化证据和方向一致性判断。
- 区分“初筛结果”和“正式筛查报告”。
- 让每个结果都有明确下一步动作。
- 保留现有静态体态、Adams 和深蹲能力的兼容路径。

### 6.2 非目标

- V2.0 不估算 Cobb 角。
- V2.0 不自动做医学诊断。
- V2.0 不以最低剪影分段或固定 8 特征作为唯一判定依据。
- V2.0 不要求所有对象完成深蹲。
- V2.0 不在缺少真实现场验证前宣称临床灵敏度或特异度。

## 7. 两级筛查产品结构

### 7.1 一级：步态剪影初筛

适用对象：进入批量筛查任务的全部对象。

采集内容：

- 5–8 秒标准化短步行视频；
- 全身持续入框；
- 前后方向和镜像状态可识别；
- 默认仅保留剪影、结构化特征和必要质控信息。

一级输出：

- `low`：当前初筛未见明显风险；
- `attention`：存在风险信号或不确定性，需要标准筛查；
- `recapture_needed`：采集质量不足；
- `review_required`：模型分布外、结果冲突或需要人工判读。

一级结果是“分诊结果”，不是正式筛查报告。

### 7.2 二级：标准筛查

触发条件：

- 一级风险达到关注阈值；
- 一级结果处于不确定区间；
- 一级与既往记录或关键点证据冲突；
- 操作员或专业人员主动升级。

标准筛查包含：

- 静态体态：整体姿态、肩/骨盆水平、躯干方向性偏移；
- Adams 前屈：手机负责动作引导和证据留存，由受训人员录入胸段/腰段观察结果；如有 ATR，只接受经验证设备或人工录入值；
- 人工复核：确认采集有效性和证据解释；
- 深蹲：按需要增加的动作控制证据，不作为脊柱正式筛查的必需项。

### 7.3 复测与随访

- 低风险对象按组织策略进入周期复测；
- 轻度关注对象进入指定时间复测；
- 复采对象必须完成合格采集后才能继续；
- 复核或进一步评估建议必须保留处理记录。

## 8. 核心功能范围

### 8.1 对象与任务

- 单个建档和批量导入；
- 创建初筛任务；
- 任务队列按“下一步动作”排序；
- 学生详情作为证据和处理中心；
- 阻塞原因、负责人和到期时间可追踪。

### 8.2 步态剪影采集

- 摄像头和入框引导；
- 自动人体剪影分割；
- 自动识别全身完整度、遮挡、距离、方向和有效帧；
- 自动判断是否具备分析条件；
- 原始 RGB 默认不长期保存。

### 8.3 协议分析

- 步态剪影：全身轮廓位置、方向性中心偏移、稳定性和模型不确定度；
- 静态体态：关键点与轮廓联合的姿态偏移；
- Adams：前屈完成度、稳定窗口和背部不对称提示；
- 深蹲：可选的重心、膝髋控制和动态偏移证据。

### 8.4 报告与证据

- 初筛分诊卡；
- 正式筛查条件检查；
- 单协议结果；
- 跨协议一致性与冲突解释；
- 数据完整度与采集质量；
- 下一步动作；
- 报告归档和复测对比。

## 9. 主流程

```text
对象进入任务
→ pending_initial_screening
→ 步态剪影采集与自动质控
  ├─ 质量不足 → pending_recapture
  ├─ 低风险且置信度合格 → 初筛通过 → pending_retest / archived
  ├─ 风险或不确定 → pending_standard_screening
  └─ 分布外或证据异常 → pending_review
→ 静态体态 + Adams（必要时增加深蹲）
→ 检查 formal_report_conditions
  ├─ 证据不足 → pending_recapture / pending_review
  └─ 条件满足 → pending_report
→ 生成并审核正式报告
→ pending_retest / archived
```

## 10. 核心业务规则

- 采集质量优先于风险判断。
- 不确定性优先于自动放行。
- 一级剪影不能单独生成正式筛查报告。
- 手机端不得根据二维画面自动输出 Adams 严重度、ATR 或诊断性结论。
- Adams 明显异常或人工记录不完整必须进入人工复核。
- 多协议方向一致可提高证据置信度，但不得转化为诊断。
- 深蹲单项异常只能形成动作控制提示，不能单独升级脊柱风险。
- 缺失证据通过状态和任务表达，不以默认正常代替。

## 11. 成功标准

### 11.1 产品指标

- 大多数对象可在一次操作中完成一级采集。
- 采集质量不足能够在分析前被识别。
- 所有结果均能映射到明确下一步动作。
- 正式报告不会在必需证据缺失时生成。
- 操作员可以从任务列表直接看到“下一步做什么”。

### 11.2 研究与算法指标

- 数据划分必须尽可能保证受试者独立。
- 阈值和模型版本可追踪。
- 必须报告敏感度、特异度、校准和不确定区间。
- 必须进行镜像、平移、距离、衣物、遮挡和设备鲁棒性测试。
- 上线前必须完成本地目标人群的前瞻性验证。

## 12. 文案边界

允许：

- “本次初筛提示需要进一步筛查。”
- “多个筛查项目出现同方向证据。”
- “采集质量不足，建议重新采集。”
- “建议由专业人员进一步评估。”

禁止：

- “AI 诊断为脊柱侧弯。”
- “预测 Cobb 角为……”
- “确认存在胸椎/腰椎侧弯。”
- “无需专业检查。”
