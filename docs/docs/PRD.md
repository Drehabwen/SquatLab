# PRD: SquatLab V1.0

## 1. 产品摘要

SquatLab 是一个聚焦深蹲动作评估的独立软件。它通过摄像头采集动作画面，提取姿态关键点，生成动作质量指标、评分、问题提示、训练建议和历史记录。

产品定位：

- 动作评估软件
- 训练反馈软件
- 数据记录与结果回看工具

产品不定位为：

- 医疗诊断软件
- 综合康复管理平台
- 机构级批量筛查系统

## 2. 目标用户

- 个人训练用户
- 体能教练
- 运动训练从业者
- 需要基础动作评估记录的教学或训练场景

## 3. 核心问题

- 缺少低门槛深蹲动作自检工具。
- 训练中常只有计数，缺少动作质量反馈。
- 用户难以持续记录动作表现变化。
- 常见代偿问题不能被及时提示。
- 训练反馈分散，难以形成结构化结果。

## 4. V1.0 目标

- 支持一次完整的深蹲评估流程。
- 支持基础计数、评分、问题提示和建议反馈。
- 支持结构化评估结果保存。
- 支持历史记录查看。
- 支持报告预览。

## 5. 非目标

- 不做医学诊断结论。
- 不做复杂账号和权限体系。
- 不做完整康复管理平台。
- 不做多动作训练平台。

## 6. 功能范围

### 6.1 采集与质量控制

- 摄像头接入。
- 用户入框和视角提示。
- 关键点检测状态反馈。
- 开始、停止和重置控制。

### 6.2 深蹲检测

- 初始站立识别。
- 下蹲和起身阶段识别。
- 单次完成判定。
- 重复次数统计。

### 6.3 评分与发现

- 深度评分。
- 稳定性评分。
- 平衡与对称性评分。
- 综合评分。
- 常见代偿提示。

### 6.4 反馈与报告

- 实时指标展示。
- 结果摘要。
- 训练建议。
- 历史记录。
- 报告预览。

## 7. 主流程

1. 进入工作台。
2. 开始深蹲评估。
3. 摄像头采集并进行姿态分析。
4. 完成至少一次有效深蹲。
5. 生成评分和建议。
6. 保存记录。
7. 在历史记录中回看结果。

## 8. 成功标准

- 用户能在短时间内完成一次评估闭环。
- 用户能看懂分数、问题提示和训练建议。
- 评估记录可回看。
- 页面和接口边界清晰，便于后续软著材料整理。
- 文案不包含医疗诊断承诺。
